Design mock-up — revision 2 — approved by the maintainer on 2026-11-15. File › New machine… builds a new, empty machine image from chosen hardware. Sample data only: boards, firmware packages, fit metadata, options, ranges and why-disabled reasons stand in for the store and the capabilities API, and digests are illustrative. Create only adds a row to this page; nothing runs, imports, pulls or writes files.

Changes in revision 2

  • Machine class lists the seven classes of the closed list; only AT 286 is available, the others show the phase that brings them.
  • New Motherboard step: four AT 286 boards. The system BIOS is picked per board from the firmware packages whose fit metadata names it, grouped by vendor, with a filter, the store or registry location, “Show incompatible” with reasons, and an empty state.
  • The video BIOS is picked per card in the video step; the XTIDE option ROM is picked per adapter under Disk controller in Drives. The combined Firmware step is gone.
  • Speed, floppy, disk-type and redistribution rules follow the chosen BIOS package, not the class. Decided: the generated configuration is open; tags follow the registry grammar; 8 MHz is 32/39.
