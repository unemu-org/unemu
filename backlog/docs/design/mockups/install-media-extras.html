Sample data only; no file is read, opened, generated or imported.

Changes in revision 2

  • “Make transfer floppy…” is now “Make transfer media…” in the toolbar, the Media menu, the details pane and the dialog title (“Make transfer media — set”).
  • The dialog chooses the medium type: Floppy is available now; Hard disk image and CD image are shown, disabled and marked “later”.
  • Decided: when the chosen extras do not fit a floppy, the dialog offers the hard disk image, attached as D:. Tick Manual.pdf in Example Adventure to see it.

      Make transfer media

      Pack chosen extras onto a generated FAT medium and insert it like any other disk. The same extras, in the same order, always give the same bytes.

      Files are written in the order shown, with fixed timestamps and a stable layout; the generated bytes are pinned so a replay inserts the identical medium. Writes by the guest go to this workspace’s journal. No host folder is shared with the guest.
