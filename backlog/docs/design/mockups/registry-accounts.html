Changes in revision 2

  • Passwords go to one credential store per operating system, detected at run time: macOS Keychain, Secret Service (GNOME Keyring, KWallet, KeePassXC) or Windows Credential Manager. With none found, the password is kept for this session only. A plain-text file is never offered.
  • “Use a Docker credential helper (later)” is shown disabled: reusing existing docker logins is planned, not built.
  • Decided: the menu item is Tools › Preferences…; destination tags are checked against the registry tag grammar; the configuration generated by New machine counts as open.

      Large blobs go up in chunks of about 64 MiB. Each accepted chunk is remembered, so an interrupted push resumes at the registry’s offset instead of starting again. Blobs the registry already has are skipped or mounted from another repository. The tag is written last.
