Design mock-up — revision 3 — approved by the maintainer on 2026-11-15. Revises the Firmware design approved on 2026-11-14 for the 2026-11-15 amendment: a licence on every layer, source archives, and descriptive metadata recorded at import. Real firmware names, licences and ROM identities; package digests, sizes, dates and documents are illustrative. No ROM or document bytes are included. Actions are previews: no file is read, imported, opened, exported or published.

Changes in revision 3

  • Import ROM folder… review: every set has a Redistribution choice. A ROM the catalogue lists as open arrives open with its SPDX licence. Every other ROM is user-supplied until you choose Open and name an SPDX licence, from the list or as a free expression.
  • For a copyleft licence (GPL, LGPL, AGPL and MPL families), Source archive… becomes required, and Import selected stays disabled, with the reason, until an archive is chosen. Try the Kiselev AT reset set.
  • The fields of each set are prefilled and editable: title, description, notes and known quirks, labels, fits (boards, machine classes, required devices), provenance (how, details, date), the licence of every layer, and a README.md generated from those fields.
  • Package pane: description, labels, provenance, the licence of every chip, document and source archive, a README section with Open README, and Edit metadata…, which publishes a new package revision with the same ROM blobs.
  • Push guard: a copyleft open ROM without its source layer shows a warning badge. Such a package (SeaBIOS here) can be pushed only to private registries.

Proposed in revision 3 — please confirm

  • A ROM the catalogue lists as proprietary (IBM here) cannot be marked open, neither at import nor in Edit metadata.
  • Catalogue-known copyleft ROMs need their source archive too; without one, you import them as user-supplied. The badge covers packages made before this rule, by earlier versions or other tools.
  • An SPDX expression counts as copyleft when any of its identifiers belongs to those families, even after OR.
  • README.md and the config are open, the README under CC0-1.0, only when every ROM, document and source layer is open.
  • A new revision must meet the current rules. Editing the SeaBIOS package therefore needs its source archive, or a switch to user-supplied.
  • Open README shows the plain-text README in the program itself. Documents still open in a host application.

Built so far: the collection, its facets, chip layout, and the Import ROM folder… scan and import. The built pane lists Used by where this mock-up shows the compatibility check under Machines in this library. Not built yet: Use in machine…, Export, document Open, and everything listed above.
