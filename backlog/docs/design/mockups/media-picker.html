Design mock-up — approved by the maintainer on 2026-11-15, all “please confirm” items included. One media picker for every Insert…, the Installation media collection’s Insert into… and Add to machine…, and pending inserts on stopped and halted machines. It builds on the approved machines, main-window and installation media mock-ups; everything not shown here stays as they show it. Sample data only: sizes, digests and dates are illustrative, and actions are previews. Nothing runs, reads a file or contacts a registry.

Changes in this design

  • One Insert… per drive — from the Media menu, the drive chip’s menu, the toolbar’s A: and B:, and Ctrl+Alt+I (Shift for B:) — opens the media picker. It replaces both Browse / catalogue… and From library…. The old dialog’s raw store path, Refresh button and list of refusal reasons are gone.
  • At the top of the picker you pick the target: the machine (fixed while it runs), the drive (switchable, with its format and what is in it now) and when the disk goes in (now, or at the next Start).
  • Search: type to search, with facets for Format, Platform, Genre, Year, Publisher and Labels, and field:value words. Each result row shows a cover placeholder, title, publisher, year, genre, disks (“2 × 1.2M”), the number of extras and whether the set is open or private.
  • Fit follows the drive’s accepted media: a 1.44M drive takes 1.44M and 720K, a 1.2M drive takes 1.2M and 360K. Sets that don’t fit are hidden behind one “N don’t fit — Show” line. When shown, they are dimmed with one short phrase, such as “Fits B: — Alt+B”.
  • Set details in the picker: pick the disk to insert, put the whole set into the drive’s catalogue in order (for Next disk), and say in plain words what happens when a program writes to the disk.
  • Sources: This machine (disks already in its catalogues) and This library. Configured remotes are listed but greyed, “after the MVP”, with a preview of a remote row and its Pull and insert.
  • Installation media collection: Insert into… (a menu of the drives that fit) and Add to machine… are enabled, and disabled only with a short reason. Make transfer media… and Export… still say “not available yet”.
  • Pending inserts: a stopped machine shows them in its details, in the drive chips (“at Start”) and in the Media menu. A halted machine takes the disk at once, and Send Ctrl+Alt+Del boots from it.

Out of scope

  • Remote search, remote rows and Pull and insert: after the MVP, with Remotes and the registry catalogue. This mock-up only reserves their place.
  • Showing the library beside a running machine; the library still shows only while no machine runs.
  • CD-ROM insertion, Make transfer media…, Export…, editing a set’s metadata, and real cover art (covers and attachments come with the registry catalogue).
  • A Previous disk command; Next disk keeps cycling through the catalogue as today.

Proposed — please confirm

  1. One Insert… per drive replaces Browse / catalogue… and From library…. The drive’s own catalogue becomes the picker’s This machine source, and a disk image file on this computer is Browse for an image file… in the picker’s footer, leading to today’s file flow.
  2. By default only sets that fit the drive are listed. One line, “N don’t fit A: (1.2M) — Show”, reveals the rest, dimmed. A dimmed row says only where it would fit: another drive of the same machine (click or Alt+B switches the drive), or “No drive in this machine takes 1.44M”.
  3. Search uses free words plus field:value (publisher:apogee, format:720k, year:1991..1993, genre:, platform:, label:), the same syntax and ranking tiers as the planned remote catalogue: title first, then publisher, genre, labels and the rest. An empty search lists sets by title.
  4. Facet counts are computed over the current result. Formats the drive doesn’t take are marked “doesn’t fit”.
  5. The disk preselected for insertion is disk 1. If the drive already holds a disk of the same set, the next disk is preselected instead.
  6. Defaults as today: Put all disks in the catalogue, in order is on, and writes go to a journal kept in the machine (“Keep the changes in DOS games”). Disks already in the catalogue keep their own setting.
  7. Into a stopped machine, Insert makes a pending insert. It belongs to the machine and goes in before the first instruction at Start; Eject (“Take out again”) or another Insert into the same drive replaces it. Into a running or halted machine, the disk goes in at once.
  8. Collection Insert into… lists the drives that fit, in every machine, the running machine’s drives first. Because the library shows only while no machine runs, it is a pending insert in practice. Choosing a drive opens the picker on that drive with the set selected, to confirm the disk and write setting.
  9. Collection Add to machine… adds all disks of the set to a drive’s catalogue and inserts nothing. This is machine state, 0 bytes, shown as a catalogue change, and Save as new image… keeps it. I chose this over making it a pending insert, which Insert into… already does.
  10. Insert into… and Add to machine… are disabled only with one short reason: “No machine has a drive for 1.44M disks”, “CD-ROM emulation not available yet” or “Damaged — repair first”.
  11. Keys: Ctrl+Alt+I and Ctrl+Alt+Shift+I (⌘I, ⌘⇧I) open Insert… for A: and B: (existing keys, new dialog). In the picker: typing searches, ↑↓ choose, Enter inserts, Alt+A / Alt+B switch the drive, Esc closes.
  12. Remote rows, after the MVP, say “Not in this library” with the download size, and offer Pull and insert: pull by digest into this library, then insert as above. A private remote first asks for a login, as Get templates does.
