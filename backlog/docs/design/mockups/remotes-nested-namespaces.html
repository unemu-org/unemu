Proposed — unemu and unemu/experimental as sibling scopes

Click either namespace or its artifact group. Each repository belongs to the longest matching prefix at a slash boundary.

Recommendation: keep configured namespaces as siblings and keep artifact groups beneath them. Nesting would express the path hierarchy, but would make a public parent appear to contain its separately scoped child and add an unnecessary tree level. Here unemu/ owns 5 repositories and unemu/experimental/ owns 11, with no duplicates. Use labels relative to the selected namespace; keep the complete reference in details and row hover text. This is a proposed label change: today the sidebar ends at artifact groups and the list uses full paths. A registry-wide view keeps full paths to avoid ambiguity.
