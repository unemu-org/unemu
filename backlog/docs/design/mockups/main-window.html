Design mock-up — revision 2 — approved by the maintainer on 2026-11-15. Sample data only. Start a machine from the list (double-click or Start), then use the menus, toolbar and dialogs. Nothing here controls an emulator.

Changes in revision 2

  • Proposed in revision 2, part of the MVP: drive chips in the status bar, one per drive the machine has, showing the image in it now, with an activity light. Hover shows the full name, the source, a short SHA-256 and the write mode; a click opens that drive’s menu (Eject, Insert…, From library…, write mode).
  • The Media menu shows the current image next to each drive.
  • Decided: Save as layer… and Save as new image… are one dialog with name and tag; a memory or drive change in Settings recomputes only the affected CMOS bytes and the checksum; 8 MHz is 32/39; image tags use x.y.z versions.

16384 KiB exceeds the 15 MiB the AT board can address above 1 MiB. A memory change recomputes only the CMOS memory-size bytes and the checksum, as SETUP would; the clock and other options are kept. The diff before Apply lists the changed bytes.

This BIOS (June 1985) has no 1.44M drive type. A drive change recomputes only the affected CMOS bytes (drive types) and the checksum, as SETUP would; the rest is kept.
