Design mock-up — revision 2 — approved by the maintainer on 2026-11-15. Save as new image… from a machine session, the tag dialogs it can raise, and Settings on an image. Sample data only; digests, sizes and CMOS byte values are illustrative. Actions are previews: nothing runs, saves or publishes.

Changes in revision 2 — the maintainer’s decisions, recorded

  • Save as layer… (Disk layers) and Save as new image… are one dialog with name and tag.
  • New disk layers saved from an open base count as user-supplied until you mark them open.
  • In Settings, a memory or drive change recomputes only the affected CMOS bytes, as SETUP would, plus the checksum; the clock and other options are kept, and the review shows the changed bytes. Try Extended or Drive B: in Settings on an image.
